# Brand assets

Health Flare + Inner Flare marketing assets, selected for this site. Canonical
source, full guidelines, and the complete kit live in
[Health-Flare/brand](https://github.com/Health-Flare/brand), pinned here to
[`v2.0.0`](https://github.com/Health-Flare/brand/releases/tag/v2.0.0).

- `marks/` — `<product>-mark-<size>-<colour>.svg` for both products, all three
  optical sizes × four colours, for the site's different colour schemes
  (Dawn/Sunrise/Dusk/Sand/Rose).
- `moment/` — the brand moment graphic for both products, all four colours —
  for hero/large-surface sections only, never used as a logo.
- `favicon/` — `favicon.svg`, PNG sizes, `apple-touch-icon-180.png`.
- `app-icons/` — just the primary (light, non-Android-specific) 1024px icon
  per product, for app-store badge / screenshot sections.

Not included (mobile-OS concerns the site doesn't have): `-dark` and
`-android-monochrome` app icon variants.

Read the full rules — optical sizes, clear space, colour contrast, lockups,
do/don't — in [`brand-guidelines.md`](https://github.com/Health-Flare/brand/blob/v2.0.0/brand-guidelines.md)
before restyling any page.
